# 台股觀察

手機上打開：

https://luke120513-sys.github.io/tw-stock/

第一次進來會看到六檔股票。想看別的，在上面打代號或名稱（例如 `2603` 或 `長榮`），點一下就加進清單。不想看了就按移除。這份清單存在自己的手機裡，換手機要重新加。

每檔只先回答一件事：**可以抄底**，或 **不行**。六個條件裡至少三個同時出現，才會寫可以抄底。這不是叫人買，股價還是可能繼續跌。

進階資訊裡才有圖和專有名詞，看不懂可以跳過。

## 每天什麼時候更新

週一到週五，台灣時間 15:30 和 21:00 會自動更新。假日或資料還沒公布時，留著上一次成功抓到的數字。

## 預設那六檔怎麼改

第一次打開的股票寫在 [`watchlist.json`](watchlist.json)。已經在手機上存過清單的人，不會被這份檔案蓋掉。

## 找得到哪些股票

上市普通股，以及 0050、0056、00878 這類 ETF。上櫃股票、權證、槓桿和反向 ETF 目前沒有。
