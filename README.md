# 台股觀察

手機上就能看的台股整理頁。網址：

https://luke120513-sys.github.io/tw-stock/

頁面上有五塊：

1. **今日大盤重點**：加權指數收盤、漲跌、成交金額，三大法人買賣超，以及近三個月指數。
2. **觀察清單**：收盤、漲跌幅、成交量、近一個月漲跌。點欄位名稱可以排序。
3. **異動提醒**：漲跌幅絕對值達到 3%、成交量達到前 20 日均量的 1.5 倍，或最低價創 60 日新低。
4. **個股分析**：價格（20 日、60 日均線與布林通道）、RSI、KD、本益比／殖利率／股價淨值比、外資買賣超。
5. **抄底訊號**：每檔 0 到 6 分。六個條件是 RSI 低於 30、KD 在低檔黃金交叉、收盤跌破布林下緣、60 日乖離小於或等於 -10%、量縮止跌、外資由賣轉買。

顏色依台股習慣：紅漲、綠跌。

抄底分數只是技術條件的核對，不是買進建議。分數高只代表跌深或超賣的條件比較多，股價仍可能繼續下跌。

## 每天什麼時候更新

週一到週五，台灣時間 **15:30** 和 **21:00** 會自動抓證交所資料並更新網頁。GitHub 有時會晚幾分鐘才跑。21:00 那次是為了補上較晚才公布的法人數字。

假日，或證交所還沒公布、暫時連不上時，網頁留著上一次成功抓到的數字，並在頁面上方說明。程式不會自己編造股價。

想立刻更新：打開 [Actions](https://github.com/luke120513-sys/tw-stock/actions/workflows/update.yml) →「更新資料並發布」→ **Run workflow**。

## 怎麼改觀察清單

編輯倉庫根目錄的 [`watchlist.json`](watchlist.json)。一個代號配一個名稱，存進 `main` 之後，下次自動更新就會改抓這些股票。

```json
{
  "stocks": [
    {"code": "2330", "name": "台積電"},
    {"code": "2317", "name": "鴻海"}
  ]
}
```

代號請用上市股票（證交所）的代號。

## 資料從哪裡來

- 加權指數、成交金額：證交所 FMTQIK
- 三大法人：證交所 BFI82U
- 個股日 K：證交所 STOCK_DAY
- 外資買賣超：證交所 T86（外陸資，不含外資自營商）
- 本益比、殖利率、股價淨值比：證交所 BWIBBU

若證交所日 K 或指數暫時抓不到，才會改用 Yahoo Finance 的公開圖表，頁面上會註明來源。本益比和法人資料沒有就留空，不會用別的數字頂替。

## 若網頁打不開

到倉庫的 **Settings → Pages → Build and deployment**，Source 選 **GitHub Actions**。

若自動更新失敗，而且日誌寫著沒有寫入權限，到 **Settings → Actions → General → Workflow permissions**，選 **Read and write permissions**。
