隱私權政策

最後更新：2026 年 11 月 4 日

沒有帳號。台股觀察不需要註冊或登入，也不向你索取姓名、電話、電子郵件或付款資料。

追蹤清單只存在你的手機裡。你加入或移除的股票代號，存在這台裝置瀏覽器的 localStorage，不會上傳到我們的伺服器。清除瀏覽器資料，或換一支手機，清單就會不見，需要重新加入。

我們不蒐集個人資料。這個網站沒有加入分析或廣告追蹤工具。

股價從公開資訊來。大盤、法人買賣和本益比等數字來自臺灣證券交易所的公開資料。個股日K在證交所無法一次提供全部歷史時，改用 Yahoo Finance 的上市股價。這些都是公開行情，不是你的個人資料。

網站放在 GitHub Pages。你打開頁面時，GitHub 可能依它自己的服務記錄基本的連線資訊（例如 IP、瀏覽器種類）。那是 GitHub 的紀錄，不是本站另外建立的會員資料。GitHub 的說明見 GitHub 隱私權聲明。

程式與資料放在 GitHub 上的 tw-stock。
